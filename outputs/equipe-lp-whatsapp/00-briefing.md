# Briefing — equipe-lp-whatsapp

## Objetivo
Equipe de agentes que produz landing pages HTML completas, focadas em conversão para WhatsApp, a partir de um briefing fornecido pelo usuário.

## Usuário-alvo
O próprio desenvolvedor/freelancer que recebe pedidos de clientes e usa a equipe para acelerar a entrega de LPs.

## Input
Briefing completo do projeto contendo: dados do cliente, nicho, tipo de LP (venda direta ou captação de lead premium), número do WhatsApp, paleta de cores, copy e referências de imagens.

## Output
Arquivo `index.html` único, responsivo, com botão WhatsApp flutuante e modal funcionando — pronto para abrir no browser e entregar ao cliente.

## Restrições
- Stack: HTML + Tailwind CDN + JS vanilla
- Sem npm, frameworks ou build process
- Estrutura de seções definida caso a caso conforme o tipo e objetivo da LP

## Métrica de sucesso
LP entregue em uma única sessão de trabalho, funcionando corretamente no browser, com o botão WhatsApp abrindo conversa com texto pré-preenchido.

## Notas adicionais
O agente responsável pela coleta do briefing (briefing-lp) deve fazer perguntas estratégicas sobre objetivo, público e oferta para ajudar o usuário a decidir o tipo ideal de LP quando houver dúvida — não apenas coletar dados passivamente.
